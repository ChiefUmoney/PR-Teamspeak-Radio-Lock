# Changelog

## v0.1.0-custom-busy

- Replaced the existing busy-tone resource with the supplied notification sound.
- Converted the sound to 16-bit mono PCM at 48 kHz, matching the previous resource's format.
- Preserved the original DLL, permit beep, package metadata, and bundled documentation.
- Added installation guidance and a two-user verification procedure.

This edition changes audio only. It does not modify transmission arbitration, hotkeys, timeouts, permissions, or the original busy-tone triggers.
